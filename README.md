# CV Application

A React CV builder app created as part of The Odin Project curriculum.

## Features

- Add general information
- Add educational experience
- Add practical experience
- Edit and resubmit information
- Live CV preview
- Responsive layout

## Built With

- React
- Vite
- JavaScript
- CSS

## What I Learned

- React components
- Props
- State management
- Controlled inputs
- Conditional rendering
- Responsive styling
